# Educational templates, data contracts and accuracy

Chatreel v2 adds original semantic templates. This guide is original Chatreel documentation; original Lemo style adaptations retain their attribution.

1. Choose the explanation before its visual theme. Themes studio, midnight, paper, ocean, coral and violet change palettes, not arithmetic. Templates are available in both Python and server Canvas; use webgl=false.
2. Scene shape: {"template":"process","title":"Follow the energy","duration":10,"narration":"...","content":{"subtitle":"...","items":[{"label":"Step one","detail":"...","icon":"sun"},{"label":"Step two","detail":"...","icon":"panel"}]}}. Copy runnable examples from templates/ rather than invent fields. No objects field in a template scene.
3. Templates: title (icon/body), concept (2–4 cards), process (2–5 steps), cycle (3–5 items), comparison (exactly 2 items), timeline (2–5 ordered milestones), bar-chart (2–6 nonnegative values, true zero baseline), line-chart (2–8 equally spaced observations), donut-chart (2–6 nonnegative parts, positive total), equation, number-line (markers within minimum/maximum), fraction (0 <= numerator <= denominator <=24), labeled-diagram (2–4 callouts and icon), solar-energy, water-cycle, recap (1–5 takeaways), quiz (2–4 options, zero-based correct), code-walkthrough (literal code, at most 9 lines, zero-based highlight).
4. Numeric chart items require label and value. unit identifies the measurement. data_kind defaults to illustrative; sourced data requires source: {"label":"Readable attribution","url":"https://..."}. Source URLs are recorded, not fetched or verified. Renderer-displayed proportions come from values. Never label synthetic examples as measured facts.
5. Equation: expression="distance / time", variables={"distance":120,"time":2}, variable_units={"distance":"km","time":"h"}, result=60, unit="km/h". Only +,-,*,/, bounded integer powers and declared variables work. The renderer verifies a supplied result but does not infer dimensional correctness; units need review.
6. Icons: sun, panel, inverter, home, battery, cloud, water, plant, book, lightbulb, atom, globe, gear, check. Icons are schematic. An atom symbol is not an accurate electron-orbit simulation. Solar-energy is a simplified energy-flow diagram, not electrical wiring; storage and grid controls are omitted. Water-cycle shows four selected processes, not a complete hydrological model.
7. Durations are whole-frame aligned. Templates need >=4 seconds; actual reading often needs 8–16 seconds. scene-metrics.json provides a heuristic recommended_duration and text boxes. It is guidance, not a measured comprehension score. Short QA clips are not pacing examples.
8. Production profile defaults to 1920x1080 at 30 fps. Preview defaults remain smaller unless dimensions are specified. Check pixel/frame budgets before encoding. Font overflow or missing glyphs fail clearly; never shrink unreadably or discard text. Bundled DejaVu has limited script coverage.
9. Use quality.json for encoded output checks, scene-metrics.json for inspectable calculations/layout, SOURCES.json for provenance and SVGs for vector inspection. These do not prove arbitrary facts. Review domain accuracy and publication suitability with the user.
