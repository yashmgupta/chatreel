# Phase 2: two runtimes, one film

The schema is an intentionally small scene language, not an arbitrary code execution API. Each scene has a duration, title, narration/caption, camera and bounded geometric actors. Global style, resolution, frame rate, seed and music cues apply to both modes. Sequential scenes have implicit cumulative start times; semantic validation additionally caps total duration at 120 seconds, 3600 frames and 1.5 billion pixel-frames, and rejects out-of-timeline music cues. Voice tts and webgl are server-only; offline downgrades explicitly to captions/2D.

Mode A: upload the source ZIP plus film-schema.json and JSON film, extract inside Code Interpreter, probe capabilities, import renderer-py via sys.path and render. Pillow draws deterministic frames, numpy generates music, ffmpeg streams raw RGB into H.264/AAC. moviepy is an optional fallback; otherwise deliver PNG/WAV/SRT with a clear missing-encoder report. Uploaded narration stays a local path supplied by the sandbox caller, never a JSON URL. No runtime network, package installation, browser, model download or TTS.

Mode B: FastAPI validates the shared schema, requires X-API-Key, and enqueues SQLite jobs with atomic claims and a single subprocess worker. Status and download require the same credential. A short-lived signed download ticket lets ChatGPT return an MP4 link without putting the API key in the URL. Server-generated HTML/JS renders trusted Canvas scenes, optionally composites them through a WebGL texture pass, and captures Chromium frames. Local eSpeak synthesizes each scene narration, rejects speech exceeding its scene and ducks numpy music under actual voice samples. ffmpeg encodes/muxes. Jobs time out, artifacts expire, disk/body/queue/frame/pixel budgets are bounded. No user HTML, JS, paths or remote asset fetches are accepted.

Deployment: one Uvicorn process with lifespan worker; SQLite and jobs on one mounted local volume. A process restart marks interrupted work failed rather than silently losing it. Horizontal scaling requires a different queue/storage design. Docker nonroot user, Chromium sandbox (no --no-sandbox), PID/memory/CPU limits; host must permit Chromium user namespaces. Configure HTTPS public base URL and stable API key before exposing the Action. No request logging of authorization or signed URLs.

The five ports preserve a recognizable subset of upstream grammar. Geometry-driven films are more constrained than agent-authored arbitrary JavaScript; detailed characters, brush engines, imported factual datasets and elaborate 3D are outside this release. Future styles must implement both backends and pass frame/render review before entering the shared enum.
